# Президентская программа на год

Статичный одностраничный сайт предвыборной программы кандидата в президенты школы.
Открывается по QR-коду с телефона.

## Что внутри

- `index.html` — весь сайт: разметка, стили и оформление в одном файле
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

Никакой сборки, зависимостей, бэкенда и базы данных. Чтобы посмотреть локально —
просто открыть `index.html` в браузере.

## Разделы

1. Турниры и спорт
2. Масштабная «Мафия»
3. «Что? Где? Когда?»
4. Ящики
5. Честно про полномочия

## Оформление

Стилистика советского агитационного плаката: состаренная бумага, красный и золотой
акценты, узкий гротеск в заголовках (Oswald), антиква в тексте (PT Serif), жёсткие
тени без размытия, толстые чёрные рамки, мотив красной звезды. Вёрстка mobile-first.

Шрифты подключаются с Google Fonts и имеют системные запасные варианты — если шрифты
не загрузятся, сайт остаётся читаемым.

## Публикация

GitHub Pages, источник — ветка репозитория, папка `/ (root)`.
